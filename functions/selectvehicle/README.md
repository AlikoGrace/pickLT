# selectvehicle

Mover-callable function (identity from `x-appwrite-user-id`) that puts one of the driver's verified vehicles in service — the "Vehicle in service" switch between a permanent owned vehicle and a time-boxed rental (plan `pickltmobile/.agent/plans/wave-2026-10/1.rental-windows-and-fleet.md` R6). Writes `currentVehicleId`, `vehicleOwnership`, the legacy `vehicle*` snapshot columns and the rental window snapshot on the profile, flips `isCurrent` between the rows without retiring either, and appends a `selected` row to `vehicle_events`. Refuses rows that are not the caller's (`vehicle.notOwnVehicle`), not verified (`vehicle.notVerified`) or rentals past their window (`vehicle.notInWindow`). Owner repo: pickltmover; the copies in pickltmobile and pickLT are byte-identical reference mirrors (`pickltmobile/scripts/check-function-mirrors.sh`).
