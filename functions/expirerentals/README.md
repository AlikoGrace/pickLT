# expirerentals

Scheduled function (`*/5 * * * *`, server key) that tidies up after rental windows (plan `pickltmobile/.agent/plans/wave-2026-10/1.rental-windows-and-fleet.md` R2/R4/R9/R10). Retires verified rentals whose `rentalEndAt` has passed (`expiredAt` stamped, event `expired`), falls the profile back to the driver's verified owned vehicle (event `fallback`) or clears it (`vehicleStatus='none'`), and notifies `vehicle_rental_expired`; drivers with a move underway are skipped until it completes. Also warns once per window (`expiring_soon` event as the dedupe key, notification `vehicle_rental_expiring`) when a rental ends within 60 minutes. Idempotent, pages in batches of 100, one failure never stops the loop. Owner repo: pickltmover; the copies in pickltmobile and pickLT are byte-identical reference mirrors.
